Git

Tech Stack: Python, OpenCV, YOLO (Ultralytics), Pygame, Twilio API, CNN Models, Video Streaming

Project Overview: A robust, real-time computer vision system designed to protect farmlands from wild animal intrusions. Utilizing YOLO object detection and OpenCV, the system continuously monitors video feeds to identify threats, leveraging a smart dual-model architecture that prevents false alarms by explicitly recognizing and ignoring humans.

Key Features & Implementation:

  • Real-Time Threat Detection: Leveraged YOLOv11/YOLOv10 models to accurately detect and classify various wildlife from live camera streams with minimal latency.
  • Dual-Model Pipeline: Integrated a separate human-detection filter to suppress false positives, ensuring farmers are only alerted when an actual animal threat is present.
  • Automated Alert System: Engineered a multi-channel notification mechanism using the Twilio API for immediate SMS alerts, paired with Pygame for local audio alarms to drive animals away.
  • Optimized for Edge Deployment: Streamlined inference and video processing pipelines to run efficiently on low-cost hardware and standard webcams, making it highly practical for rural agricultural deployment.

Secure Image Encryption using Chaos & Deep Learning

Git Live

Tech Stack: Python, TensorFlow, OpenCV, Google Colab, VS Code

Project Overview: An advanced hybrid security system that merges Artificial Intelligence (CNNs) with Chaos Theory to ensure the secure transmission of image data. The system addresses vulnerabilities in traditional encryption by utilizing deep learning for feature extraction and chaotic maps for highly unpredictable, dynamic key generation.

Key Features & Implementation:

  • Dynamic Key Generation: Employs logistic chaotic maps and deep learning to produce unique cryptographic keys for every session, effectively neutralizing key-reuse attacks.
  • Dual-Layer Security: Implements robust confusion and diffusion phases to completely scramble the original image structure and pixel values.
  • High Security Standards: Rigorously evaluated against statistical and differential attacks, achieving near-ideal Information Entropy (≈ 7.89) and a Number of Pixels Change Rate (NPCR) exceeding 99%.
  • End-to-End Pipeline: Built, trained, and tested the complete AI-cryptography pipeline using Python, TensorFlow, and OpenCV.

SmartShop: Enterprise E-Commerce Platform

Git

Tech Stack: Java 21, Jakarta EE 10, JSP, Servlets, MySQL, Maven

Project Overview: A high-performance, full-stack e-commerce web application engineered for maximum conversion and scalability. Built on modern Java EE architecture, it provides a seamless Direct-to-Consumer (D2C) and marketplace experience with robust ACID database transaction guarantees.

Key Features & Implementation:

  • Multi-Tier Architecture: Strictly separates presentation, business logic, and persistence layers using Jakarta Servlets (Controllers), DAOs, and JSP/JSTL templates for clean MVC design.
  • Atomic Transaction Integrity: Implemented robust ACID safeguards and conditional MySQL queries to completely prevent inventory overselling during high-concurrency flash sales.
  • Frictionless User Experience: Features asynchronous Fetch API calls for zero-reload cart steppers and real-time UI updates, drastically reducing cart abandonment.
  • Enterprise-Grade Security: Utilizes an AdminFilter for rigorous RBAC enforcement and secures user credentials with PBKDF2 HMAC-SHA256 cryptography.
